# Changelog

All notable changes to SeekNSee will be documented in this file.

## [Unreleased]

### Repository preparation

- Created the initial clean source-repository structure.
- Added the validated SeekNSee 0.2.5 scientific core.
- Added approved application visual assets.
- Added provisional collaboration, contribution, and security documentation.
- Marked authorship, citation metadata, license, and institutional statements as under review.

## [0.2.5] - 2026-09-24

### Scientific core

- Versioned enzyme-aware digestion and candidate generation.
- Added support for up to two missed cleavages.
- Added traceable P1-prime evaluation for Trypsin/P.
- Preserved configurable rule states: ignore, apply, and block.
- Added structured Excel output with seven worksheets.

### Packaging

- Validated and frozen portable Windows x64 distribution.
- Validated and frozen Ubuntu 24.04 LTS x86_64 distribution.
- macOS Apple Silicon packaging remains planned and experimental.
